## 📋 Sobre o Projeto

Site institucional e catálogo de produtos da **JD Embalagens**, empresa especializada em embalagens descartáveis personalizadas. O projeto foi desenvolvido para oferecer uma experiência completa aos clientes, permitindo visualizar produtos, solicitar orçamentos via WhatsApp e navegar por um catálogo organizado por categorias.

### 🎯 Funcionalidades

<details>
<summary><b>✨ Clique para ver todas as funcionalidades</b></summary>

<br/>

| Funcionalidade | Descrição |
|----------------|-----------|
| 🏠 **Home Page** | Carrossel com imagens institucionais, seções sobre a empresa, qualidade, CTA e FAQ |
| 📦 **Catálogo de Produtos** | Grid responsivo com 4 categorias: Copos, Potes, Sacolas e Outros |
| 🖼️ **Modal de Produto** | Visualização ampliada com imagem e botão de orçamento via WhatsApp |
| 🌓 **Dark/Light Mode** | Alternância entre temas com detecção de preferência do sistema |
| 📱 **Responsividade** | Layout adaptado para mobile, tablet e desktop |
| 📄 **Gerar PDF** | Exportação do catálogo em PDF para compartilhamento |
| 💬 **WhatsApp Integration** | Botão de orçamento em todos os produtos com mensagem personalizada |

</details>
